## 海床与植被

生产默认 full 的 48 个 CoralScatter 实例按 6 物种 ×（5 礁基 + 2 背景 + 1 前景）组织；`CoralScatter` 构造器自身默认 temperate 为 12，由 `main.ts` 显式选择 full。91 株海带当前布局为 51 `kelp_a` + 40 `kelp_b`，左右林带框景并保留中央水道；6 处细节海草和岩石/沙丘提供近、中、远层次。

装饰岩、远景沙丘、珊瑚和海草不自动成为碰撞体。增加视觉细节时必须检查是否造成空气墙观感、遮挡水道或让鱼穿过明显实体；真正的硬障碍仍只有五礁石及其选定碰撞路径。

## UI 与安全区

Overview 需同时检查 Console 打开和关闭；桌面 Console 改变画布 aspect，窄屏又会转为覆盖/抽屉，因此不能用一张全 UI 图代表所有构图。主体不应被顶部模式控件、右侧 Console、底部 telemetry 或 transport 遮挡。

Overview 上方空水是否过多，必须结合礁群、鱼群、鲨鱼和 HUD 一起判断，而不是单纯裁切。当前礁群屏幕位置实测见视觉基线。
