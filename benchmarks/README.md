# Benchmark data inventory

This directory contains the measured experiment data used by `docs/report/FINAL_REPORT.md` and `docs/archive/BENCHMARK_RESULTS.md`. `latest-results.csv/json` are the original untouched outputs of the performance prototype written by `npm run benchmark`; `performance-grid-vs-brute.csv/json` are identical copies kept under descriptive filenames.

## Primary data

| File | Contents | Original source |
| --- | --- | --- |
| `performance-grid-vs-brute.csv` | Summary of simulation step time by fish count and search mode | Byte-identical copy of `latest-results.csv` |
| `performance-grid-vs-brute.json` | Environment, method, summary and every per-run measurement | Byte-identical copy of `latest-results.json` |
| `ablation-results.json` | Boids rule ablation environment, method, 3-seed aggregate, all runs and samples | Generated by `npm run experiment:ablation` |
| `ablation-results.csv` | Every 30-step sample for every rule configuration and seed | Generated by `npm run experiment:ablation` |
| `ablation-summary.csv` | 3-seed aggregate per rule configuration | Generated by `npm run experiment:ablation` |
| `predator-results-seed-*.json` | Per-seed raw predator experiment results | Generated one seed at a time by `npm run experiment:predator -- --seeds=<seed>` |
| `predator-results-seed-*.csv` | Per-seed samples every 15 fixed steps | Same command |
| `predator-results.json` | Merged 3-seed results, methodology and aggregate | Generated by `npm run experiment:predator:merge` |
| `predator-results.csv` | Merged 1,920 sample rows from all conditions and seeds | Same merge command |

## Reproduce

All commands run from the project root after `npm ci`.

```bash
npm run benchmark -- --counts=100,250,500,1000,2000 --steps=120 --repeats=3 --warmup=40
npm run experiment:ablation
npm run experiment:predator -- --seeds=1270981331
npm run experiment:predator -- --seeds=1270981332
npm run experiment:predator -- --seeds=1270981333
npm run experiment:predator:merge
npm run figures
```

The command in `package.json` for the full default performance run is simply `npm run benchmark`; it uses 100–2000 fish, 300 measured steps and 5 repeats. The canonical file here used the explicit shorter command shown above to fit the current sandbox execution limit. That condition is printed in every figure and report table.

## Measurement conditions

The performance and rule experiments were executed with Node.js v22.23.4 on Linux 6.8.0, in a sandbox allocated 2 logical cores of an Intel Core i7-13700H. CPU benchmark runs create no Three.js renderer. Predators were disabled in the performance and ablation experiments to keep observation conditions stable. Full settings, seed lists, sample intervals and notes are stored inside each JSON file.

## Pilot data

`pilot/` preserves the first predator experiment iteration. Its 30-step sampling missed transient changes and its 300-step settling phase was too short; it is not used for any report conclusion. It is retained to avoid deleting real measurements and to document the method correction.

## Integrity rule

No timing is inferred from a speed-up ratio, no missing samples are filled, and no screenshot FPS is treated as hardware GPU performance. The sandbox browser uses SwiftShader; those images document rendering and interaction only.
